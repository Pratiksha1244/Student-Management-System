# Student Management System - SAP ABAP

## Project Overview
Developed a student record management system using SAP ABAP.

## Features
- Student marks processing
- Pass/Fail logic
- Multiple student handling
- Internal table processing

## Concepts Used
- Internal Tables
- Work Areas
- LOOP
- APPEND
- IF-ELSE

## SAP Transaction Used
- SE38

## Output
Displays student report with marks and result.
